# System Design Interview — Active Recall

Active-recall notes for Alex Xu's *System Design Interview: An Insider's Guide, Volume 1*.

## Weekly workflow

1. Read during the week without trying to produce polished notes.
2. On Sunday, close the book and fill in the **Closed-book recall** section for the chapters you covered.
3. Reopen the book and add only missing or corrected ideas under **Verification and corrections**.
4. Mark uncertain topics in [`REVISIT.md`](REVISIT.md).
5. Commit the week's notes so progress remains visible.

Keep each chapter concise. The goal is to retrieve and explain the ideas, not reproduce the book.
